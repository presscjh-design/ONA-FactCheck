# ONA FactCheck

**언론사 뉴스룸을 위한 AI 기반 팩트체크 도구**

기자가 기사 속 주장이나 수치를 입력하면
**Tavily**가 인터넷에서 근거 자료를 찾고(정부·공공기관 1차 자료 우선),
**Google Gemini**가 그 자료만 보고 사실 여부를 6단계로 판정합니다.
AI의 판정은 프로그램이 원문과 다시 대조해 검사합니다.

> ⚠️ **GitHub Pages에서는 실행되지 않습니다.**
> 이 프로그램은 API 키를 숨기기 위해 **Node.js 서버**가 검색과 AI 분석을 대신 처리합니다.
> GitHub Pages는 HTML·CSS·JS 같은 정적 파일만 보여 주는 서비스라 Node.js 서버를 실행할 수 없습니다.
> 이 저장소의 코드를 내려받아 **자신의 컴퓨터에서 실행**해야 합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 주장 입력과 팩트체크 실행 | 문장 하나를 넣고 버튼을 누르면 검색부터 판정까지 자동으로 진행 |
| 1차 자료 우선 검색 | 관련 국가의 정부·관계기관 사이트를 먼저 검색, 부족하면 범위를 넓혀 보완 검색 |
| 공식 언어 검색 | 외국 제도·정책은 그 나라 공식 언어로도 검색 (예: 중국 → 중국어 간체) |
| 출처 신뢰도 구분 | `1차 자료` / `공공·연구기관` / `언론 보도` / `기타` / `참고 자료(위키·블로그)` |
| 6단계 판정 | 사실 / 대체로 사실 / 일부 사실 / 대체로 사실 아님 / 사실 아님 / 판단 유보 |
| 일치 점검 | 근거마다 날짜·시점, 지역, 대상, 수치가 주장과 일치하는지 표시 |
| 원문 대조 | AI가 인용한 문장이 원문에 실제로 있는지 글자 단위로 검사, 출처 페이지의 해당 문장으로 바로 이동 |
| 자동 판단 유보 | 근거가 부족하거나 일치 여부를 확인할 수 없으면 무리하게 판정하지 않고 판단 유보 |
| 수정 제안 | 잘못된 주장은 확인된 근거만 사용해 고친 문장을 제안하고, 바뀐 부분을 강조 |
| 결과 복사 | 데스크 보고용으로 결과 전체를 텍스트로 복사 |
| 반응형 화면 | PC와 모바일 모두 지원 |

### 판정 원칙 (프로그램이 강제하는 규칙)
1. AI는 URL을 쓸 수 없습니다. 화면의 출처 URL은 모두 실제 검색 결과에서 가져옵니다.
2. AI가 인용한 문장이 원문에 없으면 그 자료는 판정 근거에서 제외합니다.
3. "사실·대체로 사실"은 날짜·지역·대상·수치가 일치하고, 인용문이 원문에서 확인된 자료가 있을 때만 유지합니다.
4. "사실 아님·대체로 사실 아님"도 날짜·지역·대상이 같은 자료에서 어긋나는 내용이 확인될 때만 유지합니다.
5. 위키백과·나무위키·블로그 등 참고 자료는 판정의 핵심 근거로 쓰지 않습니다.
6. 법률·정책·제도·출입국 규정은 정부·관계기관 자료로만 확정합니다.
7. 위 조건을 채우지 못하면 **판단 유보**로 바꾸고 화면에 이유를 표시합니다.

> AI 판정은 취재를 돕는 **참고 자료**입니다. 출처 원문을 직접 확인하고, 최종 판단은 기자와 데스크가 내려 주세요.

## 구조

```
브라우저 ──(주장만 전송)──> 내 컴퓨터의 Node.js 서버 ──> ① Tavily 검색 (최대 5건)
                                                └─> ② Gemini 분석 → ③ 원문 대조 검사
         <──(결과만 수신)──
```

- API 키는 서버의 `.env` 파일에만 있고, 브라우저로는 전달되지 않습니다.
- 서버는 `127.0.0.1`(이 컴퓨터)에서만 접속을 받습니다.
- 별도 패키지 설치가 필요 없습니다(외부 라이브러리 없음).

### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 디자인 (색은 맨 위 `:root`에서 변경) |
| `app.js` | 화면 동작 (API 키 없음) |
| `server.js` | 로컬 서버, 키 관리, 보안 설정 |
| `factcheck.js` | 검색·판정 규칙 (출처 목록, AI 지시문, 자동 점검) |
| `package.json` | 실행 명령 |
| `.env.example` | API 키 입력 양식 (실제 키 없음) |
| `.gitignore` | `.env` 등 비밀 파일을 Git에서 제외 |

## 실행 방법

### 준비물
- macOS 또는 Windows 컴퓨터
- [Node.js](https://nodejs.org) 20 이상 (LTS 버전 권장)
- API 키 2개
  - Tavily (검색): https://app.tavily.com → 가입 후 **API Keys**에서 `tvly-`로 시작하는 키 복사
  - Google Gemini (AI): https://aistudio.google.com/apikey → **Create API key**

### 1. 코드 내려받기
GitHub 저장소 페이지에서 초록색 **Code → Download ZIP**을 눌러 압축을 풀거나, Git이 있다면:
```
git clone https://github.com/<계정이름>/ONA-FactCheck.git
cd ONA-FactCheck
```

### 2. `.env` 파일 만들기
1. `.env.example` 파일을 복사해 이름을 **`.env`** 로 바꿉니다.
   (macOS Finder에서 숨김 파일이 안 보이면 **⌘ + Shift + .** )
2. `.env`를 텍스트 편집기로 열고 `=` 뒤에 키를 붙여 넣습니다. 따옴표와 공백은 넣지 않습니다.
   ```
   TAVILY_API_KEY=tvly-...
   GEMINI_API_KEY=...
   ```

### 3. 서버 켜기
터미널(Windows는 명령 프롬프트)에서 프로젝트 폴더로 이동한 뒤:
```
npm start
```
`Tavily 키: 설정됨 ✓`, `Gemini 키: 설정됨 ✓`가 보이면 성공입니다.

### 4. 사용하기
브라우저 주소창에 **http://localhost:3000** 을 입력합니다.
주장을 입력하고 **팩트체크 실행**을 누르면 20초~2분 뒤 결과가 나옵니다.

### 5. 끄기
터미널 창에서 **Control + C** 를 누릅니다.

> `index.html`을 더블클릭해서 열면 팩트체크가 실행되지 않습니다. 반드시 서버를 켜고 `http://localhost:3000`으로 접속하세요.
> 키 없이 화면만 보고 싶다면 **예시 화면 보기** 버튼을 누르세요.

## 보안 주의사항

### API 키
- 키는 **`.env` 파일에만** 넣습니다. `index.html`, `app.js` 등 코드 파일에 직접 쓰지 마세요.
- `.env`는 `.gitignore`에 등록되어 Git에 포함되지 않습니다. **`.env.example`(양식)에는 실제 키를 절대 넣지 마세요.**
- 키를 메신저·메일·채팅으로 공유하지 마세요. 사용자마다 각자 발급받는 것을 권장합니다.
- 키가 노출됐다고 의심되면 **즉시 폐기하고 새로 발급**하세요.
  - Tavily: app.tavily.com → API Keys → 해당 키 삭제
  - Gemini: aistudio.google.com/apikey → 해당 키 삭제
- 한 번이라도 GitHub에 올라간 키는 저장소에서 지워도 기록에 남을 수 있습니다. 지우는 것만으로는 부족하고 **반드시 폐기**해야 합니다.

### 서버
- 서버는 `127.0.0.1`에서만 접속을 받습니다. 같은 네트워크의 다른 컴퓨터에서도 접속할 수 없습니다.
- 서버는 화면 파일 3개(`index.html`, `style.css`, `app.js`)만 제공합니다. `/.env`, `/server.js` 등은 열리지 않습니다.
- 다른 사이트에서 이 서버를 몰래 호출하는 요청(Host·Origin 위조)은 차단됩니다.
- 오류 기록(로그)에 키가 찍히지 않도록 자동으로 가립니다.

### 데이터
- 입력한 주장은 검색을 위해 **Tavily**와 **Google Gemini**로 전송됩니다.
- Google 공식 가격표 기준으로 Gemini **무료 등급**은 입력 내용이 Google 제품 개선에 쓰일 수 있고, **유료 등급**은 쓰이지 않습니다. 엠바고·미공개 기사를 넣을 때는 유료 등급을 권장합니다.

### 인터넷 배포 시
- 이 저장소는 **개인 컴퓨터(localhost) 실행용**입니다.
- 여러 사람이 쓰는 인터넷 서비스로 배포하려면 서버 호스팅(Render, Railway, Cloud Run 등), 접속 인증, 사용량 제한, 호스팅 서비스의 환경변수로 키 관리 같은 추가 작업이 필요합니다.

## 설정 바꾸기

| 바꾸고 싶은 것 | 파일과 위치 |
|---|---|
| 1차 자료로 분류할 사이트 | `factcheck.js` → `PRIMARY_DOMAINS`, `COUNTRY_OFFICIAL_DOMAINS` |
| 참고 자료(위키·블로그)로 분류할 사이트 | `factcheck.js` → `REFERENCE_DOMAINS` |
| 사이트 주소 → 기관 이름 | `factcheck.js` → `PUBLISHER_NAMES` |
| AI 판정 지시문 | `factcheck.js` → `SYSTEM_PROMPT` |
| 표시할 근거 개수 등 | `factcheck.js` → `SETTINGS` |
| Gemini 모델 | `.env` → `GEMINI_MODEL`, `GEMINI_FALLBACK_MODEL` |
| 색상 | `style.css` → `:root` |

고친 뒤에는 서버를 껐다 켜야 반영됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `command not found: npm` | Node.js를 설치하세요. 설치 직후라면 터미널을 다시 여세요. |
| 터미널에 `키: 없음 ✗` | `.env` 파일 이름(앞에 마침표)과 키 입력을 확인하고 서버를 다시 켜세요. |
| `포트를 이미 다른 프로그램이 쓰고 있습니다` | 이미 켜 둔 서버 창이 있는지 확인하세요. |
| 화면에 `○ 서버 꺼짐` | `npm start`로 서버를 켜고 `http://localhost:3000`으로 접속하세요. |
| `API 키가 올바르지 않거나 권한이 없습니다` | `.env`의 키를 다시 확인하고 서버를 다시 켜세요. |
| `Google Gemini 서버가 지금 혼잡합니다` | Google 측 일시적 문제입니다. 1~2분 뒤 다시 실행하세요. |
| 한 번에 1~2분 걸림 | Gemini가 붐비면 자동 재시도 후 예비 모델로 넘어갑니다. 결과의 "분석 모델"에서 확인할 수 있습니다. |
| 판단 유보가 자주 나옴 | 주장에 연도·기관·지역을 구체적으로 넣어 보세요. 근거가 확인되지 않으면 일부러 유보하도록 설계되어 있습니다. |

## Render 등 인터넷 호스팅에 배포할 때

서버가 `RENDER` 환경변수를 감지하면 자동으로 호스팅 모드가 됩니다. (다른 호스팅은 `HOSTED=1`)

- 외부 접속 허용(0.0.0.0), 배포 주소(`RENDER_EXTERNAL_HOSTNAME`)만 허용
- `ACCESS_PASSWORD`(8자 이상) 필수 — 없으면 서버가 시작되지 않습니다. 접속 시 브라우저가 비밀번호 창을 띄웁니다(아이디는 아무거나).
- 요청 제한: 한 사람당 10분에 10건, 서버 전체 하루 200건 (`RATE_LIMIT_PER_10MIN`, `DAILY_LIMIT`으로 조정)
- ⚠️ 이 횟수는 메모리에만 기록되어 서버가 재시작되면 0으로 돌아갑니다. Render 무료 서비스는 15분간 접속이 없으면 잠들었다가 다시 켜지므로 하루 200건은 **요금 상한이 아닙니다.** 요금 상한은 Tavily·Gemini 계정 쪽에서 관리하세요. (결제 수단을 연결하지 않은 무료 등급 키 사용, 또는 각 서비스의 사용량 한도 설정)
- 환경변수(호스팅 화면에서 입력): `TAVILY_API_KEY`, `GEMINI_API_KEY`, `ACCESS_PASSWORD`
- Build Command: `npm install` / Start Command: `npm start` (의존 패키지는 없습니다)

내 컴퓨터에서 `npm start`로 실행할 때는 기존과 똑같이 localhost에서만 접속되며 비밀번호·횟수 제한이 없습니다.
